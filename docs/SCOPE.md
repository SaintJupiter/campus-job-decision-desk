# v0.1 冻结范围与完成状态

## 用户任务

在 15 分钟内，从用户已有的校招表中找到 5 个上海优先、满足硬条件、官方状态有依据且本人愿意投递的具体岗位。

## 已完成

1. 多格式来源的两阶段预览与不可变导入；
2. Campaign / Posting 分类、人工纠错和严格隔离；
3. 字段级 Claim、时间版本、来源冲突与适用性；
4. 确定性精确复用、模糊去重候选和人工复核；
5. 官方域、共享 ATS 租户、岗位 ID、状态与证据时间核验；
6. 简历原文证据、用户确认与偏好分离；
7. Eligibility / Evidence Fit / Trust 三轴决策与版本失效；
8. 可信短名单、服务端门禁与安全导出；
9. 只读合成演示、评测器、响应式 Web UI 与作品集文档。

## 当前验证状态

- 合成安全边界：25 / 25；
- 合成启发式样本：8 / 8；
- 私有数据结构与本地 API：已完成聚合评测；
- 外部用户任务测试：协议已完成，尚未执行，不作效果声称。

## 非目标

- 全网爬虫、自动投递、投递 CRM、简历改写；
- RAG、多 Agent、向量数据库和聊天助手；
- 自动把多岗位、多城市 Campaign 展开成具体岗位；
- 综合匹配百分比、Offer 概率、薪资预测；
- 根据 404、登录墙或搜索不到页面推断岗位关闭；
- 供应商总体排名或付费数据再分发。

## 下一版本只有一个目标

完成至少 3 名外部用户的同任务对照测试，基于最大 Bad Case 迭代一次。未完成前不扩展功能面。
