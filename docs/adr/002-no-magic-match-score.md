# ADR 002：不输出魔法匹配百分比

- 状态：接受
- 日期：2026-08-10

## 背景

“匹配度 92%”往往把资格、偏好、简历证据和信息时效混在一起；没有人工标签、基线和校准时，这个数字无法解释，也容易让缺失字段被当作满足。

## 决策

将结论拆成 `Eligibility`、`Evidence Fit` 和 `Trust` 三轴。硬条件使用三值逻辑；经历匹配必须引用已确认原文；信息可信度由来源独立性、官网证据、冲突和新鲜度决定。

## 影响

- LLM 未来最多用于结构化抽取和解释，不直接决定可投性。
- 页面不显示综合分；排序先排除明确不符合，再按证据和用户决定组织。
- 面试中可以解释每条规则、未知项与失败案例。
