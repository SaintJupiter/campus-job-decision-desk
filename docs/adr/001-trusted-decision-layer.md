# ADR 001：做可信决策层，而不是完整求职 SaaS

- 状态：接受
- 日期：2026-08-10

## 背景

Offerbiu、OfferComing 和 FreeHire 已公开展示岗位库、匹配、投递跟踪或全球 ATS 聚合能力。两周内复刻这些下游功能既缺少差异，也难形成可信评测。

## 决策

聚焦用户自带的多份国内校招表，解决聚合行粒度、跨源字段冲突、官网核验和投递前资格门禁。结果通过通用 CSV / JSON 交给现有投递工具。

## 影响

- 删除自动投递、投递看板、提醒、简历改写和聊天 Agent。
- 产品含金量由数据血缘、边界状态、评测集和真实工作流构成。
- 竞争关系从“替代现有求职平台”改为“在上游补充可信决策”。
