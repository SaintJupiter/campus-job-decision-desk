## 私有数据库结构评测

评测器通过 SQLite backup API 创建一次性副本，所有迁移和读取都在副本中完成，原数据库不被修改。公开结果只包含聚合数量：

| 对象 | 数量 |
| --- | ---: |
| DataSource | 3 |
| ImportBatch | 3 |
| RawRecord | 7,919 |
| Opportunity | 7,890 |
| OpportunityOrigin | 7,909 |
| FieldClaim | 79,648 |

结构检查：

- 7,890 / 7,890 个机会实体有原始来源；
- 7,909 / 7,919 条原始记录被物化；
- 0 组多个同时生效的 Selected Claim；
- 0 组多个同时生效的 DecisionSnapshot。

10 条未物化记录包含部分解析或拒绝记录，仍保留在 RawRecord 层，不会被转换成虚假岗位。

## 数据能支持什么

- Campaign 与 Posting 粒度问题；
- 多城市、多岗位、届次和截止字段不确定性；
- 不可变批次、字段血缘与来源独立性门禁；
- 大规模本地读取、筛选和详情展示。

## 数据不能支持什么

- 供应商总体准确率或市场排名；
- 没有完整人工 Gold 时的去重/分类真实准确率；
- 投递、面试或录用率提升；
- “官网页面开放”等于真实 headcount。

可复现聚合报告见 `evaluation/results/latest.md`；下一门槛是至少 3 名外部用户的结构化任务测试。
