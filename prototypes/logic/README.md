# PROTOTYPE — 校招岗位状态模型

这是一次性逻辑原型，不是正式产品。

## 要回答的问题

`Campaign`、`Posting`、字段级 Claim、官网核验和三轴决策能否共同表示真实校招数据中的关键边界情况，同时避免：

- 把招聘活动误当具体岗位；
- 把同名不同岗错误合并；
- 用官网某个字段覆盖官网未声明的其他字段；
- 把页面无法访问误判为岗位关闭；
- 把缺失硬条件默认为符合。

## 操作

```bash
make prototype
```

快捷键：

- `1`—`8`：选择边界案例；
- `c`：分类 Campaign / Posting；
- `d`：评估是否重复；
- `v`：应用官网核验证据；
- `e`：计算 Eligibility / Fit / Trust；
- `a`：顺序执行以上全部动作；
- `m`：循环人工结论；
- `r`：重置当前案例；
- `q`：退出。

自动查看全部案例：

```bash
make prototype-demo
```
